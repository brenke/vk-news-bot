# vk-news-bot

![CI](https://github.com/brenke/vk-news-bot/actions/workflows/ci.yml/badge.svg)

Бот для бесед ВКонтакте: по команде `/новости "тема"` ищет свежие новости в RSS крупных СМИ, отбирает 4–5 самых релевантных и присылает заголовок, краткое описание и короткую ссылку на источник.

```
📰 Новости по теме «курс доллара»

1. ЦБ оставил официальный курс доллара в размере 80 рублей
Официальный курс опустился до 80 рублей — минимум с начала месяца.
https://vk.cc/abc123

2. Аналитик допустил серьезное снижение доллара
Эксперт ждёт ослабления рубля к концу недели на фоне нефтяных котировок.
https://clck.ru/3WmkCR
Ещё: РБК — https://vk.cc/ghi789
```

Работает в любой беседе, куда добавлен бот: состояние на беседу не хранится, команда самодостаточна.

## Как это работает

```
VK Bots LongPoll
      │  message_new: /новости "тема"
      ▼
Поиск по RSS (17 источников, кэш 5 мин)
      │  фильтр по теме + свежести, дедупликация
      ▼
Склейка сюжетов: одно событие — один пункт + ссылки на другие СМИ
      ▼
Загрузка текста статей-кандидатов (до 8 страниц, ошибки игнорируются)
      │
      ▼
DeepSeek (опционально) — отбирает 4–5 новостей и пересказывает главное
      │  ссылки и даты всегда остаются из RSS
      ▼
messages.send → ответ в ту же беседу
```

Важно: **DeepSeek не ищет в интернете**. Модель только редактирует уже найденные RSS-новости. За счёт этого ссылки настоящие, а описания не содержат выдуманных фактов.

## Быстрый старт

### 1. Создайте сообщество и включите бота

1. Создайте сообщество ВК (или возьмите существующее) — вы должны быть его администратором.
2. **Управление → Настройки → Сообщения** — включить сообщения сообщества.
3. **Управление → Дополнительно → Работа с API**:
   - вкладка **Long Poll API** → **Включено**;
   - вкладка **Bots Long Poll API** → **Включено**, в **Типах событий** отметьте **Входящее сообщение** (`message_new`).
4. Там же, **Ключи доступа** → **Создать ключ** с правом **«Сообщения сообщества»** (`messages`). Скопируйте токен — он понадобится в `.env`.
5. **Управление → Настройки → Возможности ботов** → включите **«Разрешать добавлять сообщество в беседы»**.
6. Добавьте бота в беседу: **Управление беседой → Добавить бота → ваше сообщество**.

### 2. Настройте и запустите

```bash
git clone <адрес-репозитория> vk-news-bot
cd vk-news-bot
npm install
cp .env.example .env
```

В `.env` минимум:

```dotenv
VK_TOKEN=ваш_ключ_сообщества
VK_GROUP_ID=12345678          # числовой ID сообщества, без минуса
DEEPSEEK_API_KEY=sk-...        # можно оставить пустым
```

```bash
npm start
```

В логе должно появиться `LongPoll: подключение установлено`. Напишите в беседе:

```
/новости "курс доллара"
```

### 3. Проверка без ВКонтакте

Полезно, чтобы отладить поиск и формат, не трогая беседу:

```bash
npm run cli -- "футбол" --stats
npm run cli -- "искусственный интеллект" --limit 3 --json
npm run cli -- "выборы" --hours 24 --no-ai
```

Подробнее: `npm run cli -- --help`.

## Команды

| Команда | Что делает |
| --- | --- |
| `/новости "тема"` | 5 свежих новостей по теме |
| `/новости тема` | то же, без кавычек |
| `/news "тема"` | алиас |
| `!новости тема` | алиас |
| `/новости` | краткая справка |
| `/помощь`, `/start` | справка |
| `[club123\|Бот] новости тема` | команда после упоминания бота |

Кавычки включают строгий режим: все слова темы должны встретиться в новости. Без кавычек бот ищет по словам и синонимам и ранжирует по релевантности и свежести.

## Настройки

Все параметры — в `.env` (полный список с комментариями в `.env.example`).

| Переменная | По умолчанию | Зачем |
| --- | --- | --- |
| `VK_TOKEN` | — | Ключ доступа сообщества с правом `messages` |
| `VK_GROUP_ID` | — | Числовой ID сообщества |
| `DEEPSEEK_API_KEY` | пусто | Если пусто — бот работает без ИИ |
| `DEEPSEEK_MODEL` | `deepseek-chat` | Можно `deepseek-reasoner`, но он медленнее и дороже |
| `NEWS_MAX_ITEMS` | `5` | Сколько новостей в ответе |
| `NEWS_WINDOW_HOURS` | `72` | За какой период искать |
| `NEWS_MAX_CANDIDATES` | `24` | Сколько кандидатов отдавать модели |
| `NEWS_TIME_ZONE` | `Europe/Moscow` | Часовой пояс в датах |
| `NEWS_FULLTEXT` | `true` | Читать текст статьи для пересказа (нужен DeepSeek) |
| `NEWS_CLUSTER` | `true` | Склеивать новости об одном событии |
| `NEWS_CLUSTER_MAX_SOURCES` | `2` | Сколько ссылок на другие СМИ добавлять |
| `BOT_COOLDOWN_SEC` | `10` | Антифлуд на беседу |
| `LINK_SHORTENER` | `auto` | Сокращение ссылок: `auto`, `vk`, `clck`, `off` |

### Источники

`config/feeds.json` — список RSS. Добавляйте свои:

```json
{ "name": "Мой источник", "url": "https://example.com/rss" }
```

`"enabled": false` временно отключает фид. Поддерживаются RSS 2.0, RSS 1.0 (RDF) и Atom, в том числе в windows-1251.

### Синонимы для категорий

`config/synonyms.json` помогает отвечать на общие темы: `спорт`, `политика`, `экономика`, `технологии`, `наука`, `культура`, `происшествия`. Например, тема «спорт» дополнительно ищет «футбол», «хоккей», «чемпионат» и т.д. Можно дополнять своими группами.

## Деплой на VPS

### Вариант 1: systemd (Ubuntu/Debian)

```bash
sudo apt update && sudo apt install -y nodejs npm git
sudo useradd -r -m -d /opt/vk-news-bot vknews
sudo git clone <адрес-репозитория> /opt/vk-news-bot
cd /opt/vk-news-bot
sudo -u vknews npm ci --omit=dev
sudo -u vknews cp .env.example .env
sudo -u vknews nano .env      # вписать токены
```

Затем:

```bash
sudo cp deploy/vk-news-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now vk-news-bot
sudo journalctl -u vk-news-bot -f
```

В юните уже настроены автозапуск и перезапуск при падении. Если положили проект в другую папку — поправьте `WorkingDirectory` и `ExecStart`.

### Вариант 2: Docker

```bash
docker build -t vk-news-bot .
docker run -d --name vk-news-bot --restart unless-stopped --env-file .env vk-news-bot
docker logs -f vk-news-bot
```

## Ограничения и нюансы

- **VK**: лимит сообщения — 4096 символов, поэтому длинные ответы режутся на части (обычно хватает одного). Есть серверные лимиты на частоту отправки — бот их не форсирует.
- **RSS, а не полнотекстовый поиск**: нишевые темы («квантовый компьютер из ананаса») могут не найтись. Для широких тем и типичных запросов качества хватает; если нужен поиск по всему интернету — см. ниже.
- **Только свежие новости**: по умолчанию окно 72 часа, новости без даты отбрасываются.
- **Кэш**: RSS кэшируется на 5 минут, готовый ответ по теме — на 3 минуты. Повторные запросы в разных беседах не дёргают СМИ и модель заново.
- **Антифлуд**: один запрос на беседу в 10 секунд; повторный молча игнорируется.

## FAQ

**DeepSeek сможет найти вчерашние новости сам?**
Нет. API DeepSeek — это языковая модель без доступа в интернет и без актуальных данных после даты обучения. Если попросить её «найди новости за вчера», она придумает заголовки и ссылки. Поэтому поиск делает бот по RSS, а DeepSeek только выбирает и переписывает. Ссылки и даты всегда берутся из фидов.

**А можно искать по всему интернету, а не только по RSS?**
Да. Нужен поисковый API: Brave Search API (есть news-эндпоинт, ~2000 запросов/мес бесплатно), Tavily (~1000/мес) или Google Custom Search. В проекте есть точка расширения — `src/news/service.js`: вместо `loader.loadAll()` можно подключить другой источник и вернуть объекты `{ title, description, link, date, source }`. Формат ответа и логика отбора не изменятся.

**Откуда берётся пересказ?**
Бот скачивает страницу статьи (до 8 лучших кандидатов), вытаскивает первые абзацы и отдаёт их DeepSeek вместе с заголовком и описанием из RSS. Модель пишет 2–3 предложения, где первым идёт главное: что случилось, кто участвует, ключевые цифры и последствия. Ссылки и даты при этом всегда берутся из RSS, а не из ответа модели.

**Почему у некоторых новостей пересказ короче или его нет?**
Часть сайтов (например, ТАСС) отдаёт вместо статьи антибот-заглушку или пейволл. Тогда бот пересказывает по описанию из RSS, а если и его нет — остаётся заголовок и ссылка. Чтение статей можно отключить: `NEWS_FULLTEXT=false` (ответы станут быстрее и дешевле).

**Почему под новостью строка «Ещё: …»?**
Бот склеивает сообщения об одном событии: главный источник остаётся основным, а ссылки на другие СМИ показываются строкой «Ещё». Так в 5 пунктов помещается больше разных событий, а не 5 перепечаток одного пресс-релиза. Отключить: `NEWS_CLUSTER=false`.

**Как сокращаются ссылки?**
По умолчанию — через `utils.getShortLink` ВКонтакте, получаются ссылки вида `vk.cc/abc123` (метод работает с ключом сообщества). Если VK вернул ошибку, бот пробует `clck.ru`, затем `tinyurl.com`; если и они недоступны — оставляет исходную ссылку. Результат кэшируется на 30 дней, поэтому повторно сервисы не дёргаются. Отключить: `LINK_SHORTENER=off`.

**Бот не реагирует на команду в беседе.**
Проверьте по порядку: бот добавлен именно как бот (а не сообщество); включён `message_new` в Bots Long Poll API; в сообществе разрешено добавление в беседы; в логах есть входящие события. Если событий нет вообще — перевыпустите ключ с правом `messages` и перезапустите бота.

**Сообщение «VK API: Access denied» / ошибка 15.**
Бот не состоит в беседе или у сообщества нет прав на сообщения. Добавьте бота в беседу и проверьте настройки сообщений.

**Сколько стоит DeepSeek?**
На один запрос уходит примерно 2–4 тыс. токенов на вход и несколько сотен на выход. При цене DeepSeek это доли копейки за запрос. Без ключа бот работает бесплатно.

**Можно ли использовать одного бота в нескольких сообществах?**
Нет: один токен = одно сообщество. Бесед внутри сообщества — сколько угодно. Для второго сообщества запускается второй экземпляр с отдельным `.env`.

## Структура проекта

```
src/
  index.js            запуск, LongPoll, команды, антифлуд
  cli.js              проверка без ВК
  config.js           чтение .env и валидация
  commands.js         разбор /новости "тема"
  format.js           текст сообщения, даты, разбиение на части
  ratelimit.js        антифлуд
  vk/
    api.js            клиент VK API с повторами
    longpoll.js       цикл Bots Long Poll
    events.js         нормализация message_new
  news/
    feeds.js          загрузка и разбор RSS (кэш, windows-1251)
    query.js          стемминг, релевантность, синонимы
    search.js         фильтры, дедупликация, ранжирование
    service.js        поиск + DeepSeek + кэш ответов
    synonyms.js       словарь категорий
  ai/
    deepseek.js       отбор и краткие описания
config/
  feeds.json          RSS-источники
  synonyms.json       синонимы категорий
test/                 юнит-тесты (node --test)
deploy/               systemd-юнит
```

Тесты:

```bash
npm test
```
